# 01: Local design prototype of the editor

**What to build:** Design the editor's three main views as several visual directions on a local canvas, imitating n8n's structure with an own identity: (1) the canvas with the right search panel open, (2) the node detail view with inputs, settings and outputs, (3) the run view with per-node status and stop. The person chooses a direction.

**Blocked by:** none

**Status:** ready-for-agent

- [ ] At least three distinct directions per view, exported as images
- [ ] The person picked one direction and said what to change
- [ ] The choice and a short design brief are recorded in the spec
